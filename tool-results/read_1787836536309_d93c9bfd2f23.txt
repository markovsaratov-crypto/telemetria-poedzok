    61→## API CONTRACTS (для subagent'ов Worker и Frontend)
    62→
    63→Базовый URL фронтенда: относительные пути (`/api/...`). Для Worker mini-service (порт 3001) — `/api/...?XTransformPort=3001`.
    64→
    65→### Авторизация (single-user, HMAC cookie)
    66→
    67→**POST /api/auth/login**
    68→- Request: `{ "password": string }` (min 32 chars, сравнение с env LOGIN_PASSWORD timing-safe)
    69→- 200: `{ "sessionId": string, "expiresAt": ISO8601 }` + Set-Cookie `__Host-telem_session=<payload>.<sig>; HttpOnly; Secure; SameSite=Strict; Path=/; Max-Age=86400`
    70→- 401: `{ "error": "Invalid credentials" }`
    71→- 429: `{ "error": "Rate limit exceeded", "retryAfter": 60 }` (лимит 5/мин на IP, бакет `rl:auth:login:{ip}`)
    72→
    73→**POST /api/auth/logout** → 204 + Set-Cookie Max-Age=0
    74→
    75→**GET /api/auth/me** → 200 `{ "authenticated": true, "expiresAt": ISO8601 }` | 401
    76→
    77→### /api/ingest (Bearer INGEST_TOKEN)
    78→- Request: `{ "deviceId": string(1-64), "clientId": string(UUID/cuid), "points": [{lat, lon, speed?, altitude?, accuracy?, timestamp(ns), bearing?}] }` (≤1000 точек, ≤256КБ)
    79→- 201: `{ "sessionId", "pointsAccepted": int, "trafficJobId", "duplicate": false }`
    80→- 200 (повтор): `{ "sessionId", "duplicate": true }`
    81→- 400: `{ "error": "Validation failed", "field": "lat", "message": "..." }`
    82→- 413: payload > 256КБ
    83→- 429: rate limit
    84→
    85→### /api/sessions (Cookie или Bearer API_KEY)
    86→- GET `?cursor=&limit=20&olderThan=&before=&routeId=&status=` → 200 `{ "sessions": [{id, deviceId, startTime, endTime, pointCount, payloadBytes, status, route?}], "nextCursor": string|null }`
    87→- GET `/:id` → 200 `{ "id", "deviceId", "startTime", "endTime", "pointCount", "payloadBytes", "status", "points": [{lat,lon,speed,altitude,accuracy,timestamp,bearing}], "traffic": {...} }`
    88→- DELETE `/:id` → 204 (soft-delete, deletedAt=now, grace period 30 дней) | 404
    89→
    90→### /api/plan
    91→- POST `{ "startLat", "startLon", "endLat", "endLon", "sessionId?" }` → 202 `{ "jobId", "status": "pending" }` | 200 (cache hit) `{ "route": {...}, "cached": true }`
    92→- GET `/[sessionId]` → 200 `{ "route": {...}, "traffic": {...}, "status": "completed|pending|failed" }`
    93→
    94→### /api/routes (CRUD)
    95→- GET → `{ "routes": [{id, name, description, startLat, startLon, endLat, endLon, _count?: {sessions}}] }`
    96→- POST `{ "name", "description?", "startLat", "startLon", "endLat", "endLon" }` → 201 `{ "route": {...} }`
    97→- PATCH `/:id` → 200
    98→- DELETE `/:id` → 204
    99→
   100→### /api/sessions/[id]/export
   101→- POST `{ "format": "gpx"|"kml"|"json" }` → 202 `{ "jobId", "status": "pending" }` (если >5000 точек) | 200 `{ "url": "data:..."}` (sync, если мало)
   102→
   103→### /api/exports/[jobId]
   104→- GET → 200 `{ "status": "completed", "url": "/api/exports/[jobId]/download", "fileSize", "expiresAt" }` | 202 (pending) | 410 (expired)
   105→
   106→### /health
   107→- GET → 200 `{ "status": "ok", "db": "ok"|"degraded", "worker": "ok"|"degraded", "uptime": sec, "version": "2.6" }`
   108→
   109→### /api/admin/* (Bearer ADMIN_TOKEN ≥32 chars)
   110→- POST `/backup` → 202 `{ "backupId", "status": "pending" }`
   111→- POST `/restore` `{ "backupId" }` → 202 `{ "status": "pending" }`
   112→- GET `/audit?cursor=&limit=&action=&actorType=` → 200 `{ "logs": [...], "nextCursor" }`
   113→- POST `/worker/requeue` `{ "jobId" }` → 200 (requeue dead TrafficJob)
   114→
   115→### /api/worker/health (Bearer CRON_SECRET) — для Worker self-check
   116→### /api/worker/poll (Bearer CRON_SECRET) — Worker забирает pending TrafficJob (RETURNING id захват)
   117→### /api/worker/complete (Bearer CRON_SECRET) — Worker отдаёт результат
   118→
   119→### /api/import/csv (Cookie)
   120→- POST multipart/form-data `file=csv` → 200 `{ "imported": N, "sessions": [{id, deviceId, points}] }` (auto-detect columns: lat, lon, speed, timestamp, device_id, client_id)
   121→
   122→### /api/metrics
   123→- GET → Prometheus text exposition (prom-client) — `/api/metrics?XTransformPort=3000`
   124→
   125→### Cookie payload
   126→`base64url(JSON({sub:"owner", iat, exp}))` + "." + `base64url(HMAC-SHA256(SESSION_SECRET, payload))`
   127→- exp = iat + 86400 (24h)
   128→- Sliding renewal: если `exp - now < 3600` — перевыпустить в response.
   129→
   130→### Rate limit (in-memory, sandbox)
   131→- `/api/ingest`: 120/60с, ключ `IP + INGEST_TOKEN`
   132→- `/api/plan`: 5/60с, ключ `API_KEY`
   133→- `/api/auth/login`: 5/60с, ключ `IP`
   134→- `/api/admin/backup`: 1/3600с, ключ `ADMIN_TOKEN`
   135→- `/api/admin/restore`: 1/3600с, ключ `ADMIN_TOKEN`
   136→- `/api/audit`: 60/60с, ключ `ADMIN_TOKEN`
   137→- `/api/worker/requeue`: 10/60с, ключ `ADMIN_TOKEN`
   138→- Прочие `/api/*`: 60/60с, ключ `IP` (default)
